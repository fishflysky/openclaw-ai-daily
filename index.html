三步部署

快速开始

准备好 OpenClaw、Telegram Bot、SerpAPI Key，三步启动你的 AI 日报系统。

  1. 克隆仓库

    将项目克隆到本地，进入项目目录。

  2. 配置环境

    复制配置文件模板，填入你的 Telegram Bot Token、SerpAPI Key 等信息。

  3. 注册 Cron 任务

    使用 OpenClaw CLI 注册定时任务，明晚 20:00 你的第一篇 AI 日报就来了。

# 1. 克隆项目
git clone https://github.com/fishflysky/openclaw-ai-daily.git
cd openclaw-ai-daily

# 2. 复制配置文件
cp config/cron-job.example.json config/cron-job.json
# 编辑 cron-job.json，填入你的 Telegram Bot Token、SerpAPI Key

# 3. 注册 Cron 任务
openclaw cron add --job "$(cat config/cron-job.json)"

# 🎉 完成！明晚 20:00 你的第一篇 AI 日报就来了
