# Obsidian Vault 模板 — OpenClaw AI Daily

本目录是你的 Obsidian 知识库模板。Agent 会自动创建以下结构。

## 目录结构

```
AI前沿日报/
├── README.md                # 知识体系总说明
├── 知识图谱.md              # 知识图谱索引（核心页面）
├── 答案库.md                # 标准答案与解析（不展示给用户）
├── YYYY-MM-DD.md            # 每日日报（Agent 自动创建）
├── 报告/
│   └── YYYY-MM-DD-分析报告.md  # 答题分析报告
└── 概念/
    ├── Physical AI.md
    ├── Agentic Era.md
    ├── 中国AI治理.md
    ├── 中美AI差距.md
    └── ...
```

## 每日日报模板

```markdown
# 📮 AI 前沿日报 · YYYY-MM-DD

> 本期覆盖：（Agent 自动生成本期主题摘要）

---

## 🔬 本期深度观察
（Agent 自动生成 3-5 个深度观察段落）

---

## 📝 今日测验（10 题）
（Agent 自动生成 10 道选择题）
```

## 使用方式

1. 用 Obsidian 打开本目录作为 Vault
2. 打开「知识图谱.md」→ 点击 Graph View（图谱视图）
3. 你会看到一个不断生长的 AI 知识网络

## Dataview 插件推荐

安装 [Dataview](https://github.com/blacksmithgu/obsidian-dataview) 插件后，「知识图谱.md」中的查询会自动生效。
