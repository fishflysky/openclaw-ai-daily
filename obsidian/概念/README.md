# 概念页模板

此目录下的每个 `.md` 文件都是知识图谱中的一个概念节点。

## 模板

每个概念页由 Agent 自动创建，遵循以下结构：

```markdown
---
tags:
  - AI前沿日报
  - [领域标签]
created: YYYY-MM-DD
---

# [概念名称]

## 一句话定义

[Agent 自动生成的简洁定义，50 字以内]

## 为什么重要

[Agent 自动生成的核心价值说明]

## 关联概念

- [[相关概念1]]
- [[相关概念2]]

## 来源

- [[YYYY-MM-DD]] — 首次出现在日报中
```
